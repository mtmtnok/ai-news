# 基本情報技術者 合格コックピット v0.1

過去問題演習サイトで問題を解き、Notionで「次に何をするか」を決めるためのテンプレートです。

## ページ構成

1. `dashboard.md` をNotionへインポートし、トップページにする
2. `csv/01_weekly_plan.csv` を「週次計画」DBとしてインポート
3. `csv/02_focus_areas.csv` を「重点分野」DBとしてインポート
4. `csv/03_important_mistakes.csv` を「重要誤答」DBとしてインポート
5. 過去問演習レポートは `tools/prepare-dojo-csv.ps1` でUTF-8化してから「演習履歴」DBへインポート

## 設計方針

- 問題文・解説は収録しない
- 毎日の正誤入力はしない
- CSVは日別に1日1回、学習終了後に取り込む
- 重要誤答は「2回以上誤答」「理解不能」「時間超過」だけ残す
- 科目Aの23分野と科目Bの4分野を同じダッシュボードで扱う

## 演習履歴DBのプロパティ

| プロパティ | 種類 | 用途 |
|---|---|---|
| 記録名 | Title | `科目A｜2026-02-07｜ネットワーク｜1` |
| 正誤 | Select | ○ / × |
| 科目 | Select | 科目A / 科目B |
| 系統 | Select | テクノロジ / マネジメント / ストラテジ / 科目B |
| 大分類 | Select | CSVの大分類 |
| 中分類 | Select | CSVの中分類 |
| 出典 | Text | 問題名 |
| 学習日 | Date | 回答日 |
| 正解点 | Number | ○=1、×=0 |
| 取込ID | Text | 再取り込み確認用 |
| 重複確認 | Formula | 同じ取込IDの再投入を目視確認する補助 |

最初の版ではRelationを使いません。CSVの中分類をRelationへ自動接続できることを前提にすると、インポート環境によって壊れやすいためです。集計は中分類のSelectによるグループ表示とチャートで行います。

## 推奨ビュー

### 演習履歴

- 今日：学習日が今日
- 今週：学習日が今週
- 誤答：正誤が×
- 分野別：中分類でグループ化
- 月別推移：学習日を月単位、正解点を平均

### 重点分野

- 今週やる：今週の重点がON
- データ不足：回答数が10未満
- 科目A：科目が科目A
- 科目B：科目が科目B

### 重要誤答

- 今日復習：次回復習日が今日以前、克服済みがOFF
- 科目B：科目が科目B
- 克服済み：克服済みがON

## 初回検証データ

`report202607311256.csv` の実測結果：83件、正答62件、誤答21件、正答率74.7%。全件が2026-02-07の「ネットワーク」で、出典の重複はありませんでした。
